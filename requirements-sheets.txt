# Optional "sheets" extra — push the Stage 4 deliverable to a Google Sheet.

# writes data/final_output.csv and data/bonus.csv on its own. Install this only

#   3. Set GOOGLE_SHEETS_CREDENTIALS_FILE and GOOGLE_SHEET_ID (see .env.example),
#      then run:  python pipeline/05_export_to_sheets.py
